# Third-party notices

## YouTube Plus / YTLite

YTFreePlus interoperates with the free **YTLite / YouTube Plus 5.2b4** release by dayanch96. The YTLite source tree is not copied here because no repository-wide license file was found during initialization.

YTFreePlus does not contain code that bypasses the paid subscription/account system of YouTube Plus 5.2+.

## vot.js

Yandex Voice-Over Translation protocol behavior is implemented with reference to **FOSWLY/vot.js** (MIT):
https://github.com/FOSWLY/vot.js

The implementation here is a native Objective-C port and does not embed a JavaScript runtime.

## SmartTube Yandex VOT

https://github.com/Adrena1ine-ai/SmartTube-Yandex-VOT was used as an architectural reference for native-player synchronization and polling semantics. Android/Java source is not embedded in the iOS target.

## Yandex VOT

Yandex VOT is an external, undocumented service. YTFreePlus is not affiliated with or endorsed by Yandex. Protocol constants can change without notice.
